Política de Privacidade

Última atualização: 19 de fevereiro de 2026

Resumo

O Diária Fácil foi desenvolvido para controle financeiro doméstico. Seus dados são armazenados localmente no dispositivo e, quando disponível, sincronizados com iCloud conforme os recursos do app.

Dados coletados

O app não coleta dados pessoais para venda ou rastreamento de publicidade. As informações inseridas por você (como nomes, dias trabalhados, pagamentos e chave PIX) são usadas apenas para o funcionamento do app.

Sincronização iCloud

Quando habilitado, os dados podem ser sincronizados com sua conta iCloud para uso entre dispositivos do mesmo Apple ID.

Compras no app

Compras são processadas pela Apple (StoreKit). O desenvolvedor não recebe dados de pagamento, apenas o status da compra para liberar recursos Pro.
